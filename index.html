The contract

Small enough to drop in. Strict enough to trust.

  1. 01

    The component

    One custom element. Attributes for the sponsor, duration and reward. Events for every state change. No framework, no network, no tracking.

  2. 02

    The proof

    The player emits a completion claim: ad, session, elapsed time and nonce. The host verifies that claim before it becomes a receipt.

  3. 03

    The ledger

    A single use receipt grants credits. Short watches, stale claims, tampered signatures, duplicates and session caps are rejected before the balance moves.

    // host app, after the completion claim
const receipt = await issuer.issue(claim); // server
await issuer.verify(receipt);              // server
const next = creditReceipt(ledger, receipt, ad, {
  maxAds: 3,
});
ledger = next.state;

    This is a working reference, not an ad network. The sponsor is fictional. The issuer runs in your browser so the whole contract can be inspected. Production needs a server side verifier, an ad network signature and a real billing agreement. No targeting, no telemetry, no cookies.
