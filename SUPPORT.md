# Get involved

Run the local demo with Node 22.12 or newer:

```sh
npm ci --ignore-scripts
npm run dev
```

Open `http://127.0.0.1:4173/`. The sponsored card sits inside the conversation
after the assistant intro. Watch 8 seconds, earn 40 free credits for **Sage
Mini**, inspect the receipt in Developer and try to replay it. The demo issuer is
public on purpose; it proves the flow, not an ad network.

For a first contribution, start with an open issue that has a concrete scope and
a verification command. The [roadmap](docs/ROADMAP.md) names the next useful
pieces: a server verifier example, a model scoped wallet, a session store
contract, a viewability policy, a consent record, a comprehension study and an
accessibility review.

Use [Discussions](https://github.com/Automatron-workflows/ad-harness/discussions)
for questions and [Issues](https://github.com/Automatron-workflows/ad-harness/issues)
for a reproducible defect. Include the Node version, the command, expected and
actual output, and the smallest sanitized sample.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for setup, [the protocol](docs/PROTOCOL.md)
for the contract and [the community guidelines](CODE_OF_CONDUCT.md) for
participation.
